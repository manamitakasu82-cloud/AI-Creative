# \# ブランドルール（見た目と言葉のルール）

# 

# > このファイルは「AIが毎回読む、あなた専用の資料」です。

# > 色・フォント・文体のルールです。AIの作るものが、いつも同じ雰囲気になります。

# > 書き方が分からないときは、AIに「このファイルを埋めたいので、質問して」と頼めば、会話しながら一緒に書いてくれます。

#
